## Publisher description

The Class A Medical Device Database is a self-declaration database where dealers submit information on their Class A medical devices. Please note that the information contained therein has not been verified by the Health Sciences Authority (HSA). As such, HSA does not warrant the accuracy or completeness of the data, and accepts no liability for any inaccuracies or errors in the device information provided. The listing of a device in the database should not be taken as an endorsement by HSA, and notification of a device should not be misconstrued as product registration or approval by HSA. The database provides information on each device, including its name, identifier, intended use, dealer type and details, product owner, and sterility status. The Class A Medical Device Database is also publicly accessible via HSA's e-services portal at https://www.hsa.gov.sg/e-services/infosearch, under the Class A Medical Device Database' section.
