## Publisher description

This dataset provides detailed records of entities registered with Singapore's Accounting and Corporate Regulatory Authority (ACRA). It includes data fields like unique entity numbers (UEN), registration dates, entity types, street names and postal codes. This dataset is available for download in CSV format, supporting research and commercial use under an open data license. It is updated monthly.

## Export workflow

Use an export when the datastore is unavailable or a complete offline analysis is needed.

```json
{
  "name": "singapore_download_dataset",
  "arguments": {
    "dataset_id": "d_3f960c10fed6145404ca7b821f263b87",
    "action": "initiate"
  }
}
```

If the result is pending, poll on a later call:

```json
{
  "name": "singapore_download_dataset",
  "arguments": {
    "dataset_id": "d_3f960c10fed6145404ca7b821f263b87",
    "action": "poll"
  }
}
```

Wait for a ready result before using its download URL. URLs may expire. The tool returns export status and a URL; it does not load the entire exported file into the conversation. Provider availability and quota limits still apply.
