```json

  "arguments": {
    "dataset_id": "d_b5802b76f409764c16dde4bf2feb19cd",
    "action": "initiate"
  }

```

If the result is pending, poll on a later call:

```json
{
  "name": "singapore_download_dataset",
  "arguments": {
    "dataset_id": "d_b5802b76f409764c16dde4bf2feb19cd",
```
